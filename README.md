# 🚀 Tauhidul Islam Topu — Portfolio Frontend

A modern, responsive personal portfolio website built with **React + Vite**, designed to showcase my projects, technical skills, experience, and work in **Data Science, Machine Learning, Artificial Intelligence, and Full-Stack Development**.

## ✨ Overview

This portfolio provides a professional and interactive way to explore my background, development work, AI/ML projects, and technical expertise. The frontend is optimized for a smooth user experience with modern animations, responsive layouts, reusable React components, and a clean visual design.

## 🛠️ Tech Stack

### Frontend
- **React 18** — Component-based UI development
- **Vite** — Fast development and production build tooling
- **Tailwind CSS** — Utility-first responsive styling
- **React Router** — Client-side routing
- **Framer Motion** — UI animations and transitions
- **Swiper** — Interactive sliders and carousels
- **React Icons** — Icon library

### Data & Interactive Features
- **Chart.js / React Chart.js 2** — Data visualization
- **Axios** — API communication
- **React Query** — Server-state and asynchronous data management
- **React Markdown** — Markdown rendering
- **React Hook Form** — Form handling and validation
- **React Hot Toast** — Notifications
- **React Typewriter** — Typing animations
- **tsParticles** — Interactive particle effects
- **Moment.js** — Date and time utilities

### Communication & SEO
- **EmailJS** — Contact form/email integration
- **React Helmet Async** — Dynamic document metadata and SEO support

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Tauhid-Topu-007/portfolio-frontend.git
cd portfolio-frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create or update the required environment variables in your local environment files. Never commit private API keys or secrets to the repository.

### 4. Start the development server

```bash
npm run dev
```

The Vite development server will provide a local URL in the terminal, typically:

```text
http://localhost:5173
```

### 5. Build for production

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```
